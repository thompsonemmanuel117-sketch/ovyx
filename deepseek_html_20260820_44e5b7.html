AI Backend Foundation

Stage 3C

Secure AI connection architecture

Connection Architecture
┌─ Ovyx Frontend (Browser)
│ └─ POST /api/generate (user prompt)
│
├─ Secure Backend / Cloudflare Worker
│ ├─ Read GEMINI_API_KEY from env
│ ├─ Call Gemini API with structured prompt
│ ├─ Validate AI response
│ └─ Return validated project data
│
└─ Ovyx Frontend → Web Studio
The API key is NEVER exposed to the browser.
Environment Variables

The following secrets are read from Cloudflare's secure environment:

GEMINI_API_KEY—
OPENAI_API_KEY—
ANTHROPIC_API_KEY—
DEEPSEEK_API_KEY—

Secrets are never exposed to the frontend.
