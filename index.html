AI Backend Foundation

Stage 3A

Secure AI connection architecture

Connection Architecture
┌─ ForgeOS Frontend (Browser)
│ └─ POST /api/ai (user prompt + context)
│
├─ Secure Backend / Serverless API
│ ├─ Read DEEPSEEK_API_KEY from env
│ ├─ Call DeepSeek API securely
│ └─ Return AI response (no key)
│
└─ ForgeOS Frontend ← AI response
The API key is NEVER exposed to the browser. It lives only in server-side environment variables.
Cloudflare Secrets

The following secrets will be read from Cloudflare's secure environment:

GEMINI_API_KEY—
OPENAI_API_KEY—
ANTHROPIC_API_KEY—
DEEPSEEK_API_KEY—

These secrets are never exposed to the frontend. The backend reads them directly from Cloudflare's secure key-value store.

Environment Variable
DEEPSEEK_API_KEY = •••••••••••••••• (server only)

Set this variable in your deployment environment. The backend will use it to authenticate with DeepSeek.
