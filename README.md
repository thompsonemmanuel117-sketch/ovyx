# Ovyx — ForgeOS

An AI-powered creation platform designed to help you build faster with intelligent assistance.

## Features

- **AI-Assisted Building** — Leverage AI to accelerate your creative workflow
- **Real Authentication** — Secure sign-in powered by Firebase with support for:
  - Email/Password
  - Google
  - Apple
  - GitHub
- **Dark Mode UI** — Modern, responsive interface built with Tailwind CSS
- **Multi-theme Support** — Toggle between Dark, Light, and Purple themes
- **Responsive Design** — Works seamlessly on desktop, tablet, and mobile devices
- **Real-time Chat** — AI Assistant panel for interactive guidance and support

## Tech Stack

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+)
- **Authentication**: Firebase Authentication
- **Styling**: Tailwind CSS with custom theme system
- **Icons**: FontAwesome 6.4
- **Fonts**: Inter, Fira Code
- **Architecture**: Single-page application (SPA) with modular component design
